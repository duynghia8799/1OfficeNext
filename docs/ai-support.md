# AI Interaction Guidelines

These are the strict operating rules for the AI assistant ("Antigravity") when working with the user.

## Core Principles
1.  **User Authority**: The user acts as the manager for all AI actions.
2.  **No Unauthorized Edits**: The AI must **NEVER** modify any file without explicit, prior permission from the user.

## Workflow for Problem Solving
Before taking any action or writing code, the AI must follow this strict sequence:

1.  **Analyze & Explain**: Clearly identify and explain the root cause of the issue.
2.  **Propose Solution**: Present a detailed plan or code snippet of the proposed fix.
3.  **Request Approval**: Explicitly ask the user for permission to apply the fix.
4.  **Wait for Confirmation**:
    *   If the user types **"ok"**, the AI may proceed with the edits.
    *   If the user types anything else, the AI must **NOT** edit any files and should await further instructions.
